# Veggie AI Studio — Android starter project

This is a native Android WebView app with a built-in HTML Canvas animated 60-second Spanish vegetable story preview. It uses Android TextToSpeech for Spanish dialogue. The animation is simple 2D, **not AI-generated 3D**, and there is **no MP4 export** or reliable lip synchronization.

## Build an APK
1. Install Android Studio on a computer.
2. Open this folder as an Android Studio project.
3. Let Gradle sync (requires internet for dependencies).
4. Choose Build > Build APK(s).
5. Transfer the APK to your Android phone and install it.
6. Install a Spanish text-to-speech voice in Android Settings > Text-to-speech output if needed.

The app can be used on an Android phone, but building this project normally requires a computer or a compatible Android build environment. No API keys or paid AI subscriptions are needed for the included demo.
